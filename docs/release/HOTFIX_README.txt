Fallout 4 Multiplexer Renewed - 0.2.0-alpha Hotfix 2 (includes Hotfix 1)
=========================================================================

What it fixes
  Hotfix 1: with Vortex, a rebuild could leave out the rewritten copies of MCM configs, scripts and
  other configs that the previous build made. In game the MCM menus then show "Missing plugins"
  and their settings cannot be changed.
  Hotfix 2: plugins whose scripts find their records through one name (ghoulification, MUTATION,
  REPUTATION) and Respawnable Legendary Bosses compile instead of staying in the load order; the
  licence files ship with the download.
  CHANGELOG.md (sections 0.2.0-alpha-hotfix1 and -hotfix2) has the details.

How to install
  1. Close Fallout 4 Multiplexer Renewed.
  2. Extract this zip over the folder you extracted 0.2.0-alpha to, and choose to replace the
     files. Only Fallout4MultiplexerRenewed.exe and fo4mx.exe change (plus CHANGELOG.md and the
     licence files).
  3. Start the app: the bottom left now reads "v0.2.0 alpha · Hotfix 2".

After installing
  1. Scan, compile and export again (Compilation page). Your FormIDs are kept.
  2. Apply to Game, install the new "Multiplexer Output.zip" in Vortex in place of the old one,
     let it win every file conflict and deploy, then Apply to Game again.
  3. In game, open MCM: the menus of compiled mods no longer say "Missing plugins".

Requires Fallout 4 Multiplexer Renewed 0.2.0-alpha. It is not a full install on its own.
